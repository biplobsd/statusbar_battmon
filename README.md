# HyperOS Status Bar Battery Monitor

A Zygisk module for Xiaomi HyperOS that displays battery temperature and power next to the status bar clock.

## Requirements

- **Device:** Xiaomi / Redmi device running Xiaomi HyperOS (Android 14+)
- **Root Solution:** KernelSU, KernelSU Next, APatch, or Magisk
- **Zygisk:** NeoZygisk or standard Zygisk enabled in your root manager

## Download

Download the latest `statusbar_battmon-*.zip` (e.g. `statusbar_battmon-v1.1.zip`) from the [Releases](../../releases) page.

## Installation

1. Open your root manager (**KernelSU**, **APatch**, or **Magisk**).
2. Go to the **Modules** tab.
3. Select **Install from storage** and choose the downloaded `statusbar_battmon-*.zip`.
4. Once installation completes, **reboot your device**.

## Configuration

Open your root manager, locate **HyperOS Status Bar Battery Monitor** in the module list, and tap **WebUI** (or the module card) to adjust layout, padding, and settings.
